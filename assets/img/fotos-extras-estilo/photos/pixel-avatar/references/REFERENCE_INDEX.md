# Índice das referências

## 01_PRIMARY_indie_pixel_turnaround.png — REFERÊNCIA PRINCIPAL

Turnaround estilizado em 8 direções, versão mais pixelada/artística. Esta imagem define o **design oficial** do avatar.

Ordem das vistas:

| Posição | Arquivo individual | Direção |
|---|---|---|
| linha 1, col. 1 | `primary_views/01_front.png` | frente / 0° |
| linha 1, col. 2 | `primary_views/02_front_right.png` | frente-direita / 45° |
| linha 1, col. 3 | `primary_views/03_right.png` | direita / 90° |
| linha 1, col. 4 | `primary_views/04_back_right.png` | trás-direita / 135° |
| linha 2, col. 1 | `primary_views/05_back.png` | costas / 180° |
| linha 2, col. 2 | `primary_views/06_back_left.png` | trás-esquerda / 225° |
| linha 2, col. 3 | `primary_views/07_left.png` | esquerda / 270° |
| linha 2, col. 4 | `primary_views/08_front_left.png` | frente-esquerda / 315° |

Use estas vistas para reconstruir volume e validar silhueta. Como são sprites produzidos artisticamente, pequenas inconsistências entre vistas devem ser resolvidas escolhendo uma geometria 3D plausível e coerente.

## 02_SECONDARY_clean_pixel_turnaround.png

Versão mais limpa e menos pixelada do mesmo design. Serve para esclarecer:
- estrutura do cabelo e mullet;
- roupa e dobras principais;
- proporções corporais;
- relação camiseta/jaqueta;
- calça e calçado.

Nunca deixe esta referência substituir a linguagem visual da `01_PRIMARY`.

## 03_IDENTITY_portrait.png

Fotografia real. Serve como referência de **identidade**, especialmente:
- sobrancelhas;
- olhos;
- sorriso;
- bigode/goatee;
- nariz e contorno facial;
- tom de pele;
- textura/volume do cabelo.

Não use a fotografia para tornar o modelo fotorrealista. O avatar final deve continuar estilizado e alinhado aos sprites.
