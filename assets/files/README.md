# Public files

Place only files that are safe to publish on the open web.

- `cv/`: academic CVs and curriculum versions.
- `certificates/`: general academic certificates unrelated to a specific project.
- `research/[project]/`: `papers/`, `preprints/`, `slides/`, `posters/`, `presentation-photos/`, `certificates/`, and `supplementary/`.

Use the canonical project slugs and filename conventions in [the asset manifest](../ASSETS_MANIFEST.md). Store original presentation photographs with project documents; put web images in `assets/img/` only when the site displays them.

Do **not** upload academic transcripts, IDs, application cover letters, confidential institutional data, unpublished co-authored material without permission, or documents containing personal identifiers.
